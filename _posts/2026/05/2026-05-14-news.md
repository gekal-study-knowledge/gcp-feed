# GCP Updates - 2026-05-14

## GKE Security Bulletins

### GCP-2026-033

<td>
<p>A container breakout vulnerability CVE-2026-46300 has been found in the Linux kernel, known as Fragnesia. It allows an unprivileged local attacker to escalate to root on the host.</p>
<p>GKE Standard clusters with Ubuntu nodes are impacted. GKE Standard clusters with Container-Optimized OS nodes are not impacted. GKE Autopilot is not impacted.</p>
<p>Clusters using GKE Sandbox aren't impacted.</p>
<h4 id="what-should-i-do_1" tabindex="-1">What should I do?</h4>
<p>Upstream kernel patches have only recently been released. Those patches are being built into GKE releases and this bulletin will be updated when they are available. In the interim, partial mitigations are available below. Containers do not provide a robust security boundary, as container breakout vulnerabilities pose a significant risk. For secure workload isolation, we recommend using <a href="https://docs.cloud.google.com/kubernetes-engine/docs/how-to/hardening-your-cluster#gke_sandbox">GKE Sandbox</a>.</p>
<p>If possible, migrate your workloads to run as non-root. If your container needs to be root, consider setting the <code dir="ltr">pod.spec.securityContext.seccompProfile.type</code> to <code dir="ltr">RuntimeDefault</code> for all workloads in your cluster. As an added security measure, we also recommend setting the <code dir="ltr">pod.spec.containers[*].securityContext.allowPrivilegeEscalation</code> to <code dir="ltr">false</code>.</p>
<div></div><pre dir="ltr"><code dir="ltr">apiVersion: v1
kind: Pod
metadata:
  name: default-pod
spec:
  securityContext:
    seccompProfile:
      type: RuntimeDefault
  containers:
  - name: mycontainer
    image: ubuntu
    securityContext:
      allowPrivilegeEscalation: false</code></pre>
</td>
