<h2 class="release-note-product-title">Google SecOps</h2>
<h3>Feature</h3>
<p><strong>Publisher Agent Version 2.7.2</strong></p>
<p>Publisher Agent Version 2.7.2 is now available.</p>
<p>This release includes the following updates and fixes for the Publisher and remote agent:</p>
<ul>
<li><strong>Alert lazy loading for remote actions:</strong> Remote action tasks now support loading case data on demand from the server when alert lazy loading is enabled, reducing task payload sizes.</li>
<li><strong>Integration dependency installation fix:</strong> Fixed an issue where installing integrations with multiple interdependent dependency files could fail before all packages finished installing.</li>
<li><strong>Remote agent deletion fix:</strong> Fixed directory permissions when running the self-destruction script during remote agent deletion.</li>
<li><strong>Publisher stability and security updates:</strong> Improved Publisher resilience and addressed security vulnerabilities.</li>
</ul>
